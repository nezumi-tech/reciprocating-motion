# 往復運動の運動力学インフォグラフィックス (Reciprocating Motion Kinematics)

変位振幅が同一の往復運動について、「速度一定制御」「加速度一定制御」「加加速度一定（S字）制御」の3方式（および単振動）の運動力学的特性を、リアルタイム同期アニメーションと連動グラフで直感的に比較・解説するインタラクティブなWebアプリケーションです。

## 主な機能

- **リアルタイム往復運動シミュレーター**:
  - 3つのキャリッジ（台車）が実時間で同期して往復運動。
  - 折り返し時の衝撃パルス（速度一定）や、Jerkスパイク（加速度一定）を視覚エフェクトで再現。
  - 搭載ワークの「残留振動（バネ・マスモデル）」を物理シミュレーションし、S字制御の圧倒的な低振動性を実証。
- **4連動時間変化グラフ ($x, v, a, j$)**:
  - 変位 $x(t)$、速度 $v(t)$、加速度 $a(t)$、加加速度 $j(t)$ を同一タイムライン上にリアルタイム描画。
  - 現在時刻を示すタイムライン追従バー。
  - マウスホバーで瞬時に各時点の数値をインスペクト。
- **インタラクティブ・コントロール**:
  - 再生 / 一時停止 (Spaceキー)
  - 先頭リセット (Rキー)
  - タイムライン・シークバーによる任意時刻へのスクラブ
  - 再生速度切り替え（0.25x / 0.5x / 1.0x / 2.0x）
  - ストローク振幅 $L$、周期 $T$ のリアルタイム調整
  - 単振動 (Harmonic) 比較トグル
  - ダークモード / ライトモード切り替え
- **工学インフォグラフィック解説**:
  - 各制御方式の特性比較マトリックス表（数式次数、最大値、メリット・デメリット、実機用途）。
  - なぜJerk（加加速度）が現代の超精密位置決め・搬送で最重要なのかを掘り下げた解説カード。

## 構成ファイル

- `index.html`: セマンティックなHTML構造とUI
- `style.css`: モダン・サイバー工学デザインシステム（グラスモーフィズム、ダーク/ライトテーマ）
- `kinematics.js`: 厳密な数理運動方程式エンジン＆残留振動シミュレータ
- `app.js`: アニメーションループ、Canvas同期描画、イベント制御

## 公開・ホスティング

静的ファイル（HTML / CSS / JS）のみで動作するため、Cloudflare Pages、GitHub Pages、Vercel 等にそのままデプロイ可能です。
